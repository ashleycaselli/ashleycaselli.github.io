{{- /* Site-level override of the module's partial of the same name, adding two cases the module does not have: `placeholder = true` and `sourcedLocally = true`. The module requires every section to name exactly one of `query` or `view`, which is right — a section with no source is almost always a mistake. Two sections here are the exception, and both resolve to no query at all, which the module's run-query.html already handles by returning no rows: placeholder the query is being rewritten. The page should stay in the nav, holding its place with its `empty` message, until the new query exists. sourcedLocally a content adapter in this site builds the section instead — see content/events/ and content/talks/. Without this the module's adapter would fetch and publish the same rows a second time, because a site-level adapter adds to the module's rather than replacing it. `sourcedLocally` hides the source from the module, not from everybody: the adapter that does build the section passes `localAdapter` and gets the query resolved as usual. Only that one flag tells the two callers apart — they ask the same partial the same question. Everything else is the module's behaviour, reproduced. If either flag is ever added upstream, delete this file — the module's version wins again the moment this one is gone. Args: section (a section dict), label, localAdapter (optional) Returns: dict of "queryId" and "params". */ -}} {{- $sec := .section -}} {{- $label := .label | default $sec.id -}} {{- $mine := .localAdapter | default false -}} {{- $queryId := "" -}} {{- $params := $sec.queryParams | default dict -}} {{- if or $sec.placeholder (and $sec.sourcedLocally (not $mine)) -}} {{- /* No source the module should act on, deliberately. Nothing to resolve, nothing to fetch. */ -}} {{- else -}} {{- if and $sec.query $sec.view -}} {{- errorf "nanopub-hugo: section %q sets both query and view — pick one (a view already names its query)" $label -}} {{- end -}} {{- if not (or $sec.query $sec.view) -}} {{- errorf "nanopub-hugo: section %q sets neither query nor view (set placeholder = true for a section with no source yet, or sourcedLocally = true for one this site builds)" $label -}} {{- end -}} {{- with $sec.view -}} {{- $resolved := partial "nanopub/resolve-view.html" (dict "view" . "label" $label) -}} {{- $queryId = $resolved.query | default "" -}} {{- with $resolved.targetField -}} {{- $target := $sec.target | default "$ORCID" -}} {{- $params = merge (dict . $target) $params -}} {{- end -}} {{- else -}} {{- $queryId = partial "nanopub/resolve-query.html" (dict "query" $sec.query "label" $label) | default "" -}} {{- end -}} {{- end -}} {{- return (dict "queryId" $queryId "params" $params) -}}
